# Twincedar 1.0 TEST
Native Java/Canvas Android 8+ Doppelblock between-sums puzzle.

Cycle blank, dark block, 1, 2, then blank. Every row and column must contain exactly two dark blocks, one 1 and one 2. Each outside clue is the sum of the digits strictly between its two blocks. Zero means adjacent blocks. Gold given digits or gold-dot given blocks cannot change. Twelve distinct 4x4 clue boards have twelve different unique solutions; some include zero, one or two given cells.

Saved cedar palette and cell guides, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, account or requested permissions. Settings and completed-puzzle marks stay on device. External studio link opens browser.

Independent Java enumeration finds all 216 boards with line multisets 0,0,1,2; its sorted-list and between-block sublist sums agree with production value-frequency and first/last-block scans. Every legal Latin board plus 30000 seeded random blank/block/digit states per puzzle agree. Unique solution, fixed cells, bounds, solve, undo and replay pass. Adapter navigation, saved settings, privacy, cell taps, next, levels and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current 803-entry registry, 117 partial recovered README records and exact Seamwillow cumulative stage found no Doppelblock match. Crustvale uses the 1 and 4 digits as sandwich endpoints in a fully numbered Sudoku with 2x2 boxes. Here two repeated dark blocks per line are movable endpoints; only 1 and 2 fill remaining cells, with no boxes. The joint block-placement and digit-placement problem uses line multisets and between-block sums rather than a Sudoku sandwich. Copperfield uses outlined regions and non-touching equal digits; those constraints are absent here. Detour was rejected because Bendhollow already implements room turn counts on an all-cell loop. Known Doppelblock genre, not a global invention. Partial recovered corpus, not ALL-local. Rules: https://www.cross-plus-a.com/html/cros7dpbl.htm and https://sumaddle.com/fundamentals.html .
